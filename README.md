# KO External Links New Tab

> Lightweight WordPress plugin to automatically open outbound links in a new browser tab with secure `rel="noopener noreferrer"` attributes.

## Overview

Keep visitors on your website longer. **KO External Links New Tab** automatically detects external links in post and widget content and opens them in a new tab without altering your internal links.

## Features

* **Auto External Target:** Injects `target="_blank"` on external outbound links.
* **Security Hardened:** Adds `rel="noopener noreferrer"` attributes for security.
* **Preserves Internal Links:** Internal pages continue opening in the same browser window.
* **Zero Front-End Assets:** Pure PHP execution with 0 bytes of extra CSS or JS loaded on public pages.
* **Instant Dashboard Toggle:** Manage and toggle the feature directly from the **KO Plugins** dashboard.

## Installation

1. Click the green **`< > Code`** button at the top of this repository and select **Download ZIP** (or download from [Releases](../../releases)).
2. In your WordPress admin dashboard, navigate to **Plugins -> Add New Plugin -> Upload Plugin**.
3. Choose the downloaded `.zip` file and click **Install Now**.
4. Click **Activate Plugin**.
5. Manage settings directly under the **KO Plugins** dashboard menu.
